# Docs

What each document is for, grouped by who reaches for it. Finished reports,
audits and superseded plans live in `archive/`; nothing there describes the
current build.

## Writing anything a player reads
- `voice-bible.md` - the house voice. Every string, store copy included.
- `i18n.md` - how the six languages are built and checked.
- `sensitivity-audit.md` - the read-through for anything that could land badly.
- `ip-rename-map.md` - real names the game must not ship, and what replaced them.

## Building and testing
- `testing.md` - the probes, the suite, what CI runs and when.
- `contrast-audit.md`, `skins.md`, `palette-migration.md` - colour, the palettes and the accessibility numbers.
- `match-drama.md` - how the live match is staged.

## The game's design
- `womens-game.md`, `womens-challenges.md`, `womens-kits.md` - the women's world.
- `roadmap.md` - where the game could go.
- `working-list.md` - worth building, not being built yet.

## Money, ads and the stores
- `monetisation.md`, `monetisation-spec.md`, `pro-manager.md` - what is sold and how.
- `ads-plan.md`, `ADS-STEP-BY-STEP.md`, `ads-privacy-draft.md` - the adverts in the store builds.
- `store-listing.md` - the listing copy in six languages.
- `release-readiness.md` and `launch/` - what has to be true before a build goes to the stores.

## Releases
- `release-notes-1.9.0.md`, `release-notes-1.9.1.md`, `release-notes-1.9.2.md` - what changed, in players' words.
